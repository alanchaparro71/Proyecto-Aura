# AURA 2.0
## Descripción
AURA 2.0 es una experiencia web interactiva basada en HTML, CSS y JavaScript.
El proyecto simula una inteligencia artificial ficticia capaz de interactuar
con el usuario mediante efectos visuales, reconocimiento de voz, modos
emocionales y animaciones dinámicas.
---
## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Canvas API
- Web Speech API
- LocalStorage
---
## Funciones principales
- Sistema de memoria del usuario.
- Personalización de colores.
- Modos emocionales:
  - Feliz
  - Tranquilo
  - Motivado
  - Creativo
  - Misterioso
- Efectos visuales:
  - Partículas interactivas.
  - Fondo de estrellas.
  - Modo Matrix.
  - Modo Cyberpunk.
- Asistente AURA:
  - Mensajes generados.
  - Síntesis de voz.
  - Reconocimiento de comandos por voz.
